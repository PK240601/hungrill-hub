# Hungrill Hub

A premium, interactive, single-page business website designed for **Hungrill Hub - GRILL and BBQ in Irinjalakuda**, Thrissur. 

This website showcases authentic Arabian fast food, signature Al-Faham options, and customer-favorite Iranian shawarmas using modern design aesthetics and smooth interactive elements.

## Features

- **Fiery Amber Visual Theme**: A dark-mode obsidian first design with warm ambient glowing accents, smooth hover triggers, and page scroll entrance animations.
- **Authentic Interactive Menu**: Live real-time search and filter tabs (Al Faham, Shawarmas, Others) to browse actual signature dishes.
- **Genuine Reviews Carousel**: An auto-sliding and manual-controlled testimonial deck showing actual customer feedback from online profiles.
- **Responsive Layout**: Designed from the ground up to render beautifully on mobile devices, tablets, and desktop displays.
- **Contact & Map Integration**: Easy links to call directly, physical address details, and an interactive embedded location map of Railway Station Road, Irinjalakuda.

## Tech Stack

- **Core**: Semantic HTML5 & Modern ES6+ Javascript
- **Styling**: Pure CSS3 variables & Glassmorphic layouts (no bulky framework dependencies)
- **Icons**: Font Awesome v6

## Running Locally

To run the project on your machine, you don't need any complex installation or Node.js environment. You can serve it using Python's built-in HTTP module:

1. Clone the repository:
   ```bash
   git clone <your-repository-url>
   cd Hungrill
   ```

2. Run the local development server:
   ```bash
   python -m http.server 8000
   ```

3. Open your browser and go to:
   ```text
   http://localhost:8000
   ```
